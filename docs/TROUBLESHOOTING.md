# Troubleshooting

## Runtime Delivery Denied

Check:

- Script visibility is `public` or `unlisted`.
- Script build is ready.
- Access mode matches the credential provided.
- Free key or premium license is valid and not expired/disabled/revoked.

Related docs: `features/ACCESS_MODES.md`, `runtime/DELIVERY_SESSIONS.md`, `api/REFERENCE.md`.

## Free Key Does Not Validate

Check:

- Key is not expired.
- Key was generated by the current Work.ink flow.
- Key format matches current implementation.
- The target `LUXY-FREE-XXXX-XXXX-XXXX` format is a reviewed migration target, not current behavior.

Related docs: `features/KEYS.md`, `audits/POST_RC_POLISH_AUDIT.md`.

## License Delivery Fails

Check:

- License belongs to the requested script.
- License status is active.
- Customer identifier is present and normalized as expected.
- Assignment capacity is not exhausted.
- Assignment status is active.

Related docs: `features/LICENSES.md`, `features/LICENSE_ASSIGNMENTS.md`.

## Events Do Not Reach Webhook

Check:

- Event secret is not logged or changed.
- Runtime signature generation matches the integration guide.
- Queue worker is running.
- Dead-letter page contains delivery failures.
- Webhook destination is healthy.

Related docs: `features/EVENT_PLATFORM.md`, `operations/EVENT_QUEUE_RUNBOOK.md`.

## Dashboard Profile Looks Incomplete

Check:

- Display name and username are stored in the profile table.
- Avatar URL is optional.
- Email and password are managed by Supabase Auth.
- Role is read-only in the dashboard.

Related docs: `dashboard/DASHBOARD_WORKFLOWS.md`.
